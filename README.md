# Airwar Pacific!

The WWII Pacific air-war card game (Triumph Games, 2006), as a web app.

**Play:** open the GitHub Pages address for this repository in your phone's browser. On iPhone, tap Share → Add to Home Screen; launched from the home screen it runs full screen like an app. On Android, use Install app / Add to Home screen.

Everything runs in the browser; games are saved on the device.
